# 黒猫のウィズ 調査記録

『クイズRPG 魔法使いと黒猫のウィズ』（コロプラ・2013〜）のゲームサイクルとUIを、
リデザインの土台として調べた記録です。**仕様書（`wiz-redesign-spec.md`）と
画面設計書（`wiz-redesign-screens.md`）は、ここに書いた事実の上に立っています。**

## 1. ゲームの骨格

**クイズに正解することが、そのまま攻撃になります。** これが一文の要約です。

- 精霊（カード）を5枚組み合わせてデッキを作り、クエストに挑む **◎**
- クイズに正解すると、精霊の能力（攻撃・回復など）が発動して敵を削る **◎**
- クイズはRPGの「コマンド入力」の位置にあります。**知識が強さに直結する**構造で、
  このプロジェクトが最初から狙っていたものと同じ形です

> 「精霊の問いかけ（＝クイズ）に答えることで攻撃や回復といった精霊（カード）の
> 能力を発動させてクエストクリアを目指します」

---

## 2. 1問の流れ — ここが黒ウィズの芯

```
問題が出る → 20秒以内に答える → 正解 → チェイン+1 → AS発動 → 敵を殴る
                              ↘ 不正解/時間切れ → 攻撃できない・チェイン半減
```

### 制限時間は20秒 **◎**

不正解、または20秒以内に答えられなかった場合は不正解となり、**攻撃できません。**

### 速く答えるほど、多くの精霊のASが発動する **◎**

**かつては「5秒以内ならEXCELLENT、それ以外はGOODでAS不発」という0か1かの仕様でした。**
8周年アップデートで、**解答時間に応じて発動する精霊の数が変わる**ように改められています。

| 判定 | 発動するAS |
|---|---|
| EXCELLENT | 5体 |
| GREAT | 4体 |
| GOOD | 3体 |
| NICE | 2体 |

**正解すれば最低でも2体は発動します。** 旧仕様では「5秒を超えるとデッキ右側の1〜3体の
ASが発動しない」という形で、**デッキの並び順が意味を持っていました** ○。
右に置いた精霊ほど落ちやすいので、**編成順そのものが速さへの賭け**になります。

**20秒のうち5秒が EXCELLENT の境目** ＝ 持ち時間の 1/4 です。この比が、
形式ごとに持ち時間を変えるときの手がかりになります。

---

## 3. チェイン **◎**

- 戦闘画面の**右上**に出る数値。正解すると +1
- **1チェインにつき1%のダメージアップ。** ダメージに `(100 + チェイン数)%` の補正が
  かかり、**AS にも SS にも乗ります**
- **誤答するとゼロではなく半減** — アプリver 2.5.0（2017-03-16）で、それまでの
  「誤答で0に戻る」から変更されました
- 表示は99でカンスト（後に999まで対応）、内部値はさらに上まで数えています

**「◯チェイン以上でダメージアップ」を持つ精霊と、チェインを上乗せする精霊を
組み合わせる**のが定石です。**チェインは、連続正解という行為そのものを
資産に変える装置です。**

---

## 4. 属性と相性 **◎**

5属性。**火・水・雷**が三すくみ、**光・闇**が相互有利です。

```
火 ─▶ 雷 ─▶ 水 ─▶ 火        光 ◀─▶ 闇
```

| | 倍率 |
|---|---|
| 得意属性へ | **1.5倍** |
| 同属性・無関係 | 1.0倍 |
| 苦手属性へ | **0.5倍** |

光・闇は互いに1.5倍。火水雷の3属性とは相性を持たず、すべて等倍です。

---

## 5. 精霊のスキル — AS と SS **◎**

**ほぼすべての精霊が2種類のスキルを持ちます。**

| | 発動 | 性格 |
|---|---|---|
| **アンサースキル（AS）** | クイズに正解すると**自動で**発動 | 受け身。速さと編成順で本数が決まる |
| **スペシャルスキル（SS）** | 規定の正解数が溜まると**自分で**発動できる | 能動。切り札 |

- SS は精霊ごとに決められた正解数を溜めると使えるようになります。
  **未覚醒でも最低3回の正解が要ります**
- **発動するとカウントは0に戻り**、また溜め直しです
- AS にも「3Chain以上」「HPが80%以上」のような**追加の発動条件**を持つものがあります
- SS の効果は攻撃・回復・バフにとどまりません。**選択肢を減らす・制限時間を止める**
  といった、**クイズゲームならではのもの**があります

**この「クイズの条件そのものを動かすスキル」が、黒ウィズを他のRPGと分けています。**

---

## 6. デッキ **◎**

- **5枚編成**
- **コスト上限**があり、プレイヤーのレベルで上限が上がります
- **コスト超過でも挑戦はできますが、全精霊のパラメーターが25%ダウン**します
  （禁止ではなく代償。**降りるかどうかがプレイヤーの手にある**形です）
- 属性を揃えると「純属性強化」などの恩恵があります
- 回復ASを2体入れると回復が追いつく、残りはアタッカー、というのが定石 ○

---

## 7. クエストと魔力 **○**

- クエストは**魔力**（他ゲームのスタミナ）を消費して挑みます
- **魔力は3分で1回復**します。クエスト開始時に回復までの残り時間は切り捨てられ、
  2:59から数え直しになります
- メインクエストは章立て。**ノーマルとハードがあり、ハードは敵の構成はほぼ同じで
  スペックと使用スキルが大幅に強化**されています
- 月に2回ほどのペースでイベントクエストが追加されます

---

## 8. 出題形式 **○**

**基本は4択です。** イベントなどで次の形式が出ます。

| 形式 | 中身 |
|---|---|
| 4択 | 基本形 |
| 並べ替え | 文字や語を正しい順に並べる |
| 穴埋め | 文中の空所を埋める |
| 一問多答 | 当てはまるものを複数選ぶ |
| グループ分け | 選択肢を2つ以上の組に振り分ける |
| 線結び | 左右の項目を線で対応づける |
| スライド | 盤面を滑らせて答えを作る |
| パネル | 盤面のパネルを選ぶ／めくる |
| 文字つなぎ | 文字を順につないで語を作る |
| 画像クイズ | 写真・イラストを見て答える |

「全部で9種類」という記述と、上の一覧はゆるく食い違います **△**。
**数え方（画像クイズを形式に数えるか）の違いと見ています。**

**このうち「文字つなぎ」「パネル」「一問多答」は、このプロジェクトの
文字パネル・消去法・スワイプとほぼ同じ操作です。** 形式の移植で新規に作るものは
多くありません。

---

## 9. ジャンル **○**

- クイズのジャンルは**全10種**。そこから**6つを選んで**出題されます
- 初期状態でも6ジャンルが設定済み。設定画面で入れ替えられます
- 確認できたジャンル名 — **英語**（単語の意味を問うものが多い）、**計算**
  （パネルの色が増えるほど式が複雑になる）、**ニュース**（1990年代・2000年代など
  年代で出る）。ほかにアニメ・ゲーム・スポーツ・学問の系統があります

**「どのジャンルで出題されるかをプレイヤーが選ぶ」のが黒ウィズの形です。**
苦手を避けることも、鍛えることもできます。

---

## 10. 育成 **○**

| 手段 | 中身 |
|---|---|
| **強化合成** | 素材を食わせてレベルを上げる。**魔道書**が経験値効率で圧倒的 |
| **進化** | 最大レベルにしてから進化させる |
| **潜在能力解放** | エーテル系のカードを合成して潜在能力を開く |
| **限界突破** | さらに上限を超える |

**育成の主素材が「魔道書」＝本である**のは、このプロジェクトの
「知識カード」と発想が近い場所です。

---

## 11. 画面について **△**

**画面まわりだけは裏が取れませんでした。** UI解説ページ（`gameui.matme.info`、
`univ-bpb.tech`）はどちらも遮断されています。確実に言えるのは次の2点だけです。

- **チェインは戦闘画面の右上**に出る **◎**
- **デッキの精霊は左から右に並び、右側ほどASが落ちやすい** ○
  （＝**画面上の並びが、そのままルール**になっています）

このほか「マイホーム画面で背景・エフェクト・BGMを設定できる」「メニュー →
オプション → アカウント設定」という階層が確認できました ○。

**画面設計書は、この2点と一般的なクイズRPGの作りから組み立てた再構成です。**
黒ウィズの画面の写しではありません。**そこは断定していません。**

## 12. このプロジェクトに写せるもの・写せないもの

| | 黒ウィズ | ここでの扱い |
|---|---|---|
| クイズ＝攻撃 | 芯 | **そのまま写す。** 既存のwave構造がすでに近い |
| チェイン | 芯 | **そのまま写す。** 連続正解が資産になる |
| 速さでAS本数 | 芯 | **写す。** ただし持ち時間は形式ごとに変える |
| AS / SS | 芯 | **写す。** MCHのPassive/Active Skillを当てる |
| 属性相性 | 芯 | **写す。** MCHの5勢力を当てる |
| デッキ5枚 | 芯 | **写す** |
| ガチャ | 中心的な収益源 | **入れない**（原則2） |
| 魔力（スタミナ） | 中心的な導線 | **入れない**（原則4の精神） |
| レアリティ＝強さ | 前提 | **入れない**（原則1・強さの源は知識） |
| 進化・限界突破 | 育成の柱 | **知識カードの網羅率に置き換える** |

**下の4行が、このリデザインでいちばん考えたところです。** 詳しくは仕様書の §1 と §11。
