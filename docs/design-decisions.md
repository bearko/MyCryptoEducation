# 設計判断の記録

「なぜこうなっているのか」を残すためのファイルです。検討して**却下した案**も、理由とともに書いてあります。

---

## 出発点

決まっていたのは2点だけでした。

- 歴代の英雄（My Crypto Heroes のキャラクター）を使う
- 知的好奇心・知識欲を満たすゲーム性であること

コトダマンや Scrabble のように「知識が多いほど強くなれて、知識をつける過程そのものが楽しい」方向を探し、最終的に**世界の義務教育カリキュラム**を題材に選びました。

### なぜカリキュラムだったか

コトダマン型の面白さは3点に分解できます。

1. 探索空間が巨大（語彙は事実上無限）
2. 知らなくても部分点が取れる
3. 知った瞬間に強くなる実感がある

カリキュラムはこの3つを満たしたうえで、**「同い年の12歳が別の国で何を学んでいるか」という比較軸**を持っています。学年（縦）・国（横）・年代（時間）の3軸で難易度を動かせるので、単なる難問化に頼らずに驚きを作れます。

### 検討して採らなかった題材

| 案 | 却下理由 |
|---|---|
| 共通点コンボ（英雄同士を共通属性で繋ぐ） | 「正しい接続」の辞書を用意するのが最大の難所。Wikidata で代替可能だが、初手としては重い |
| 六次の隔たり（英雄間の最短経路） | 同上。将来の拡張候補としては有力 |
| 論証バトル（史実カードで勝敗を論じる） | 判定にLLMが必須になり、コストとブレが読めない |
| 錬成型ディスカバリー（Little Alchemy型） | 組み合わせ表の作成量が膨大 |

## 体験設計の5段階

```
1. 12歳の問題、まだ解けるな            → 解ける爽快感
2. この領域は忘れているな。でもヒントで解ける → 忘却の自覚
3. 習っていない単元が来た。どうすれば     → 翻弄
4. 英雄が教えてくれる                  → 発見
5. 他の国の問題も解けるようになってきた   → 成長
```

### 核心：不正解が最大の報酬になる経済設計

普通のクイズゲームは正解が報酬なので、③で壁にぶつかった瞬間「損をした」と感じて離脱します。このゲームでは**③の翻弄は④の解説を解禁するための入場券**です。

そのため「解けなかった＝この単元の解説が開いた＝知識カードを1枚得た」という形にし、負けたときに手に入るものを軽くしていません。③→④の橋がここです。

### 壁の作り方

学年を上げて難しくするのではなく、**「12歳」という座標を固定したまま国だけ差し替えます。** 同い年の子が解いている問題が解けない、というショックが一番効きます。

同じ手が時間軸にも使えます。現行課程の「四分位範囲」「箱ひげ図」「2進法」は、大人にとって文字通り習っていない領域です。学年は下がるのに解けなくなる。

### トーンが成否を分ける

「知らない」を突きつける言葉選びが、翻弄を屈辱にするか好奇心にするかを決めます。不正解時は「間違えました」ではなく**「面白い単元に当たった」**と英雄が言います。この方針は文言を書き換えるときにも守ってください。

## 却下した案とその理由

### ✗ 装備の量で難易度ゲージが削れる

当初「強化するほどクイズが簡単になる」という案でしたが、**装備の量でゲージが削れると、成長実感が知識から素材に移ります。** ガチャの構造そのもので、コンセプトが静かに裏返ります。

→ ゲージを削る主体を知識カードにし、装備は「関連としてカウントされる範囲」を広げる触媒に限定しました。バトル前に内訳を必ず表示します。

### ✗ 魔石の確率ドロップ

運の期待値で回させると、10問が作業になります。→ 解いた教科から確定で落ちます。

### ✗ カレンダーの連続ログインボーナス

連続日数を報酬に紐づけた瞬間、動機が「知りたいから」から「途切れさせたくないから」に移り、途切れた日に自己嫌悪が発生します。ガチャの射幸心とは別種ですが、同じくらいコンセプトを壊します。

→ 記録装置に限定。スタンプは押すが、途切れてもペナルティも警告もなし。価値は振り返りの質（先月の自分が解けなかった問題を辿れる）に置きます。

### ✗ GUM で魔石を買えるようにする

魔石が買えると「数学ばかり解いていると火の魔石が枯れる」という圧力が消え、**苦手分野に手を出す動機がゲーム内から失われます。** GUM で買えるのはクリスタルなど分野に依存しない素材だけです。

### ✗ Legendary の装備を素材だけで作れるようにする

最上位の装備が素材の量だけで手に入ると、また「素材＝強さ」に戻ります。→ Legendary のレシピにだけ知識カードの所持数を条件に入れます。

### ✗ 得意な範囲だけ選べる状態で放置する

学年と科目を選べるようにすると、人は得意な場所しか選びません。→ 「おまかせ」を既定にして知識マップの白いマスから優先出題し、**10問目は必ず範囲の外**から出します。切れ目に既知を置くと手が止まります。

### ✗ 自由入力のLLM判定

コストとブレが読めないため採用しませんでした。→ ビルド時に表記パターン（漢字・かな・カナ・英語）と接尾辞バリアントを事前生成して照合します。誤字脱字は不正解扱いで構わない、という判断です。

---

### ✗ クリスタルを手に入れたら知識カードが1枚付く

実装計画 §0 で「強く推したい」と書いた案ですが、**採りませんでした。**

知識カードは難易度ゲージを削る唯一の手段です。クリスタルは GUM で買えるので、
入手で知識カードが付くと **GUM でゲージの削り具合が買える**ことになります。
原則1「強さの源は知識であって、素材ではない」がそのまま裏返ります。装備の量で
ゲージが削れる案を却下したのと同じ理由です。

→ **鉱物の話（`fact`）は、手に入れると読めるようにするところまで。** ショップで
伏せておき、買うと開きます。知識としては受け取れて、ゲージには影響しません。
「素材が知識の器になる」という狙いは、ゲージを介さずに満たしています。

理科の出題に鉱物を使うのは別の話で、そちらは問題として出せば知識カードが付きます。
**解いて得るぶんには何の問題もありません。**

## 各機構の意図

| 機構 | 意図 |
|---|---|
| **知識マップ**（教科×学年の格子） | 空白を本人に気づかせる。ゲームから「あなたは地学が苦手です」と言われると不快になるので、図で見せて本人に発見させる |
| **知識カード** | 英雄解放の鍵。集めた分野が挑める相手を決める。解放条件を素材量ではなくカード枚数にすることで、コレクションが知識に紐づく |
| **3段階ヒント** | 英雄の得意分野なら3段階、専門外なら2段階。英雄を編成する意味が生まれる。**スコアは減るが知識マップの塗りは減らない**（ヒントを使ってでも解いたことを肯定する） |
| **応用編** | 正解者へのストレッチ。同じ単元を横か上にずらす。知識マップのマスが緑になり、「解けた」と「掘った」が区別される |
| **別の英雄によるTips** | 講義の延長ではなく雑談の角度。英雄同士の関係が見える副産物もある。2〜3文で止める |
| **赤い○** | 日本の答案の丸つけの再現。正解＝赤い円をペンで描く演出 |
| **チャレンジの4段階の問い方** | **答えは同じまま、問い方だけが変わる。** ゲージが削れると難易度ではなく「その人物への距離」が縮む。負けても知識が増えれば次回は最初から削れている（持ち越しを別変数で持たない） |
| **レアリティ別のゲージ上限** | Common 30 / Uncommon 45 / Rare 60 / Epic 80 / Legendary 100。最初の1体が数セッションで落とせて、Legendary は装備を揃えないと届かない |

## クリスタル100種について

CC0 で公開されている素材ですが、図鑑を見ると**100種すべてが実在の鉱物・元素**です（Gold, Sulfur, Graphite, Iron, Lithium, Chromium, Tellurium, Obsidian, Amber, Pearl…）。

つまり理科（化学・地学）のコンテンツそのものなので、**入手した瞬間にその鉱物の知識カードが1枚付く**設計にできます。素材が知識の器になり、素材集めがコンセプトから浮きません。**強く推したい設計です。**

価格も図鑑の希少度から自動算出できます。

```
price(GUM) = max(5, round(50 / scarcity_percent))
```

Iron 8 GUM、Amethyst 102 GUM、Red Diamond 5,000 GUM。100種すべてに妥当な値がつきます。

## データソース（将来の拡張用）

問題の元ネタは手書きのサンプルですが、本格的な拡張では次を使う想定です。

| 国 | ソース | 状態 |
|---|---|---|
| 🇯🇵 日本 | 文科省の学習指導要領コード＋**学習指導要領LOD**（RDF/Turtle、SPARQL） | **新旧両方が入っているので、旧課程との差分がクエリで取れる。**「あなたの世代には存在しなかった単元」を機械的に抽出できる |
| 🇺🇸 米国 | 1EdTech **CASE Network 2**（全50州・主要4教科、API） | 閲覧は自由、API利用は登録制 |
| 🇬🇧 英国 | GOV.UK National Curriculum | Open Government Licence |
| 🌏 国際比較 | OECD **Future of Education and Skills 2030 Curriculum database**（Excel） | 「インドの数学」「欧州の第二外国語」の裏付けはここ |
| 参考 | UNESCO-IBE 国別ドシエ | PDF中心、機械可読ではない |

**カリキュラムは「何を教えるか」の目次であって「問題」ではありません。** 問題文は自作かLLM生成が必要です（教科書・入試過去問はそのまま使えません）。逆に目次が構造化されているので、細目コードを与えて問題を生成させる設計が素直に成立します。

粒度が国ごとにバラバラなので、**自前の中間トピック体系を1枚挟んで各国コードをマッピングする**構造にしないと後で破綻します。この中間層が結局ゲームのワールドマップになります。

## 未決の論点

- クリスタル100種の族分類（貴金属・宝石・元素・鉱石・生物起源・石英の6族への割り当て）
- クリスタル1種ごとの豆知識テキスト100本
- 接尾辞リストの拡充と、`suffixStrip: false` にすべき問題の洗い出し
- 地図ピン方式で使う地図データ（Natural Earth などのPDデータが候補）
- 問題データをスプレッドシートで書いてJSONに変換する経路を用意するか
- テンポ優先モードの自動送り時間（現在0.75秒）が適切か
