# 黒ウィズ型リデザイン 画面設計書

仕様は `wiz-redesign-spec.md`、調査は `wiz-research.md`。**この文書は「どの画面に
何を置くか」だけを決めます。** 数式とルールは仕様書にあります。

## 0. 番号の決まり

**既存の S-01〜S-33 は使い回しません**（過去のレビューの番号が別の画面を指すように
なるため）。**新しく `W-` の体系を立てます。**

**番号はブロックで空けます。** 途中に差しこまずに済むよう、10きざみで区切ります。

| 帯 | 中身 |
|---|---|
| W-01〜W-04 | 起動とホーム |
| W-05〜W-08 | クエストへ向かう |
| W-10〜W-14 | デッキ |
| W-20〜W-30 | バトル |
| W-31〜W-35 | ポップアップ |
| W-40〜 | 集める・育てる（既存画面の引き継ぎ） |

**`npm run validate` は「重なり」だけをエラーにし、「抜け」は許します。**
S体系（詰める）から変わる点なので、`scripts/screens.mjs` 側に書いてください。

**判定は `views.screenId()` が持ち、一覧は `scripts/screens.mjs` が持ちます。**
2つに分けたまま、`npm run shots` が撮るたびに突き合わせる形は既存のままです。

## 2. 共通の決まり

### 高さの割り当て（バトル画面・100dvh）

**主役は設問と解答です。** バトルはその上に細く畳みます——大きく取ると、
問題を読む前に戦況を読むことになります（既存の決まり）。

| 層 | 高さ |
|---|---|
| 敵とチェイン | **18%** |
| 持ち時間バー | **6px**（固定） |
| 補足（教科・単元・段・ヒント・⚙） | **6%** |
| 設問 | **24%** |
| 解答 | **36%** |
| パーティHPとデッキ5枚 | **14%** |

**数値入力と文字パネルでは、デッキ行を顔だけの 7% に畳みます**（キーボードと
盤面に高さが要るため）。SSゲージは顔の下の点で示します。

### 出さないもの

| 出さないもの | なぜ |
|---|---|
| 平均回答時間・自力回答率などの統計 | 原則3-2。判定はその場かぎりの表示 |
| 所持GUM（ショップ以外） | 既存の決まり |
| 「あと◯問」以外の進行の数字を二重に | ヘッダの束の帯が持っている |
| ガチャ・魔力・課金の導線 | 入れない（仕様書 §1） |

### 色

勢力の色は仕様書 §2 の5色。**背景はMCHの `Image/Backgrounds/*.png` を教科ごとに
敷きます**（1000×1500・縦長のまま）。**方眼紙の地はバトル以外で残します。**

**変えるところ**

- **主役層をデッキにします。** これまで「挑む相手のカルーセル」が置かれていた

**変えないところ**

- ステータス層（アイコン・称号・名前・残バッテリー・時刻・知識マップの進み具合）
- マインちゃんの吹き出し（文字数ぶん伸び、3行を超えたら9pxまで縮む）
- 背景はホーム全体に敷く。3層（上段は内容ぶん・下段32%・主役層が残りを吸収）
- **どれだけゲージを削れるかはホームに出しません**（既存の決まり）

**既存 S-04 の作り直し。柱3つ（文字で説明しない・選択肢を増やさない・

┌────────────────────────────────┐

│                                │
│  ┌──────────────────────────┐   │

│  └──────────────────────────┘   │
│  ┌──────────────────────────┐   │
│  │ [背景]   りか  小4           │   │
│  │ 👹黄竜  👹白虎  👹朱雀★       │   │
│  │ 4択6 ・ 数値3 ・ 消去法4      │   │
│  │ 知識カード ×13              │   │

│  ┌──────────────────────────┐   │
│  │ [背景]   じょうほう  中1      │   │
│  └──────────────────────────┘   │

**足すもの**

- **敵の属性を3つ、札の中に出します**（`👹朱雀 👹玄武 👹青龍★`）。★がボスです。
  **これがデッキを選ぶ理由になります** ——文字の説明は置かず、顔と色だけで示します

**変えないもの**

- 教科は毎回くじで3つ。**ホームへ戻って入り直しても引き直しません**

- 科目名は、その漢字を習う学年まで ひらがな（`engine.subjectLabel`）
- **札の右側は知識カードの枚数**（GUMやクリスタルは「必ずこれ」と書けない）
- 1画面に収める（`.sel` が 100dvh の3層）。スクロールさせない

## W-10 デッキ編成

**新規。黒ウィズの芯がここにあります。**

```
┌────────────────────────────────┐
│  ← 戻る        デッキ              │
│                コスト 42 / 51      │
├────────────────────────────────┤
│   1     2     3     4     5      │
│ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐  │
│ │顔 │ │顔 │ │顔 │ │顔 │ │ ＋ │  │
│ │朱雀│ │玄武│ │朱雀│ │青龍│ │   │  │
│ │ 13│ │  9│ │  6│ │ 13│ │   │  │
│ └───┘ └───┘ └───┘ └───┘ └───┘  │
│  ⚔  ⚔  ⚔  ⚔  ⚔                 │  ← 装備（SS）
│ ●●●  ●●●●  ●●●  ●●●●●●  −      │  ← SSゲージの長さ
├────────────────────────────────┤
│  速く答えるほど、右まで届く           │
│  ┌─────────────────────────┐    │
│  │NICE ▓▓░░░ GOOD ▓▓▓░░       │    │
│  │GREAT ▓▓▓▓░ EXCELLENT ▓▓▓▓▓│    │
│  └─────────────────────────┘    │
├────────────────────────────────┤
│  この編成での到達度               │
│  夏目漱石へ  46% → 58%           │
└────────────────────────────────┘
```

**ここで見せたいことは1つだけです** ——**左が先で、右ほど落ちる。**

- 枠の下の帯が、**判定ごとにどこまでASが届くか**を4段で示します。
  文字の説明は「速く答えるほど、右まで届く」の1行だけ
- **枠を長押しで入れ替え**（ドラッグ）。押すと W-11（ヒーローを選ぶ）
- **⚔ を押すと W-12**（エクステンション＝SSを装備）
- SSゲージの●の数は必要正解数（初伝3・中伝4・奥伝6）
- **コストが上限を超えたら、上の数字を朱で出して「−25%」を添えます。**
  **止めません**（決定2・降りるかどうかはプレイヤーの手）

**到達度の before/after は既存の装備画面から持ってきます**（誰への到達度を
見るかを選べる形もそのまま）。**初伝ひとつの効きは1%に満たないことがあるので、
整数で同じに見えるときだけ小数第1位まで出します。**

- 色が判定の境目で変わります：EXCELLENT帯は金、GREAT帯は銀、GOOD帯は青、
  NICE帯は灰。**「いまどの帯か」が色だけで分かります**
- **数字（残り秒）は出しません。** 秒を読むと問題を読む時間が減ります
- **ヒント／設定を開いているあいだは止めます**（仕様書 §4）

**デッキ行**

- 顔40px ×5、その下にSSゲージの点。**溜まった枠は縁が光ります**
- **押すと W-33（SSを撃つ）。** 溜まっていない枠は押せません
- **ASが発動した枠は、判定のあと順に光ります**（左から・80msずつ）。
  **どこまで届いたかが見えることが、速さの手ごたえです**

**変えないもの**

- 補足の行（教科・単元・段・ヒント・⚙）。**ヒントは小さく畳む**（原則5の道具）
- 短い選択肢（6文字以下）は2×2
- `stem` があれば問題文の上に大きく
- 写真はクレジットとセットでしか出さない

## 3. 演出のタイムライン

**1問あたりの演出は、合計 1.1秒を超えないでください。** 8秒のスワイプ束で、
演出が1.5秒あると、**触っている時間より見ている時間のほうが長くなります。**

| ms | 何が起きるか |
|---|---|
| 0 | 答えた。持ち時間の時計を止める |
| 0–150 | 判定（EXCELLENT…）が出る。チェインが +1 して弾む |
| 150–550 | **デッキが左から順に光る**（80ms × 発動本数） |
| 250–850 | AS の effect スプライトが敵の上で回る（81コマ・約600ms） |
| 400 | ダメージ数字が出て、敵のHPバーが減りはじめる |
| 850–1100 | 敵のHPバーが減りきる。倒れたら崩れる |
| 1100 | 解説へ（設定なり）／スワイプは次の問題へ |

**SSのカットインだけは別枠で 1.2秒**とります。**自分で押したときだけ出るので、
待たされている感じになりません。**

## 4. 実装で先に決めておくこと

**画面に落とす前に、この4つを確かめてください。**

1. **バトル画面の高さが本当に収まるか。** 敵18% + 補足6% + 設問24% + 解答36% +
   デッキ14% ＝ 98%。**`npm run touch-check` でしか分かりません**
2. **スワイプ8秒が短すぎないか。** 写真を見て2択を払うのに足りるか。
   **実機で触らないと分かりません**
3. **デッキ5枠が360px幅に並ぶか。** 顔40px × 5 ＋ 間隔で 240px。入りますが、
   **SSゲージの点が読めるか**は見ないと分かりません
4. **持ち時間バーがレイアウトを動かさないか**（`transform: scaleX` で縮める。
   `width` を動かすと再レイアウトが走ります）
