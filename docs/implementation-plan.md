### CryptoCrystal — CC0確認済み

公式ブログ（2021年8月27日）で明示されていました。創業チームがコレクション全体をCC0のもとでパブリックドメイン（No rights reserved）にすると決定し、それ以降、誰でも個人・商用を問わず、理由や制限なしにオリジナルのコレクションを利用できるとあります。これはコレクション内の一部のピース、構成要素、キャラクター、そしてコレクション全体のいずれにも適用されます。

**ただし1点だけ注意があります。** 記事末尾に商標の但し書きがあり、CC0は商標権には影響しないため、当面のあいだ「Official」「CryptoCrystal」「CryptoCrystal(s)」といった名称を作品中で使わないよう求められています。

**対応：アートは自由に使い、名前は使わない。** ゲーム内では「クリスタル」または独自の総称を用い、CryptoCrystalという固有名は出しません。個々の鉱物名（Gold、Beryl、Obsidian など）は一般名詞なので問題ありません。クレジットは任意ですが、CC0である旨とプロジェクトへの謝辞をクレジット画面に置くのが礼儀にかなうと思います。

- 図鑑：`https://cryptocrystal.app/picturebook`（100種・名称・希少度）
- 画像：`https://cryptocrystalio.s3.us-west-1.amazonaws.com/crystals/characters/{001-100}.png`

### クリスタル100種が、ただの素材以上のものになる

図鑑を取得して気づいたことがあります。**100種すべてが実在の鉱物・元素です。** Gold, Silver, Copper, Sulfur, Graphite, Diamond, Iron, Lithium, Chromium, Mercury, Tellurium, Obsidian, Amber, Pearl……。

つまりこれは**理科（化学・地学）のコンテンツそのもの**です。素材を「クラフトのために消費するもの」で終わらせず、**入手した瞬間にその鉱物の知識カードが1枚付く**設計にできます。Beryl を手に入れたらベリリウムの豆知識が付き、それが理科の出題や、キュリー夫人・ダ・ヴィンチのチャレンジのゲージ削りに効く。

**素材が知識の器になる。** ここまで来ると、素材集めがコンセプトから浮きません。強く推したい設計です。

### Wikipedia画像

使えます。実装方針は前回のまま。

- 問題データに `commons: "File:xxx.jpg"` を持ち、ビルド時に Commons API で `extmetadata` を取得してライセンス情報を焼き込む
  `https://commons.wikimedia.org/w/api.php?action=query&titles=File:X&prop=imageinfo&iiprop=url|extmetadata&format=json`
- CC BY-SAは商用利用も改変も可能だが、著作者のクレジットとライセンス条項の明示が必要で、改変した場合は同じライセンスで公開する義務が生じる
- **PD と CC BY を優先し、CC BY-SA は避ける。** 画像に矢印や注釈を描き込む問題を作ると、その加工画像の配布条件に波及するため。美術作品は元がPDのことが多いので、そちらから選べば悩まずに済む
- ホットリンクは技術的には可能だが推奨されていないので、ビルド時に自前の `public/` へミラーする

## 1. 確定した設計方針

| 論点 | 結論 |
|---|---|
| カレンダー | 記録専用。連続日数ボーナスもペナルティも入れない |
| GUM | 魔石は買えない。クリスタルなど汎用素材のみ |
| 自由入力 | LLMを使わない。ビルド時に表記パターンを事前生成 |
| 問題DB | GitHubリポジトリで管理、Vercelへデプロイ |
| レンジ許容幅 | 正解年から自動算出 |

魔石とGUMの役割分離はこうなります。

- **魔石** — 知識の副産物。解いた教科から確定で落ちる。買えない
- **GUM** — 行動量の副産物。解いた問題数に応じて貯まる。クリスタルを買える

数学ばかり解いていると火の魔石が枯れてクラフトが詰まる。GUMではクリスタルしか買えないので詰まりは解消されない。**苦手分野に手を出す動機がゲーム内から発生します。** 知識マップの空白を埋めさせたい設計と噛み合います。

| 鉱石 | Pyrite, Hematite, Magnetite, Chalcopyrite | 理科（地学） |
| 生物起源 | Amber, Coral, Pearl, Obsidian, Asbestos | 国語・理科 |
| 石英 | Quartz, Amethyst, Agate, Onyx, Citrine | 算数・数学（結晶構造） |

### 2-2. ショップの価格は希少度から自動算出

図鑑に scarcity(%) が載っているので、手で値付けする必要がありません。

```
price(GUM) = max(5, round(50 / scarcity_percent))
```

| 鉱物 | 希少度 | 価格 |
|---|---|---|
| Iron | 6.592% | 8 GUM |
| Copper | 6.250% | 8 GUM |
| Graphite | 3.950% | 13 GUM |
| Amethyst | 0.488% | 102 GUM |
| Red Diamond | 0.010% | 5,000 GUM |
| Hauynite | 0.010% | 5,000 GUM |

価格レンジ 8〜5,000、中央値 102。100種すべてに自動で妥当な値がつきます。

- 品揃えは固定（日替わりランダムにすると「良い品が出るまで待つ」というガチャ的待機が生まれる）
- 知識カードの累計枚数で上位の族が解放される
- **買えるが、解いて得るより高い。** これが価格設計の原則

## 3. 出題エンジン

### 3-1. 重複の解消（最優先）

現在、指定範囲の在庫が10問に満たないと同じ問題を循環させています。外国語で10問同じになったのはこれが原因です。

- セッション内でユニークを保証
- 在庫が10問未満ならその数だけ出題し、「この範囲は現在N問です」と明示
- 出題選択画面に在庫数を先に表示

### 3-2. 解説スキップ

- 出題選択画面に「正解した問題の解説を見る」トグルを設置、状態を保持
- OFF時：赤丸の演出（0.5秒）→ 自動で次へ。獲得物は画面上端に小さく流す
- **不正解時は設定に関係なく必ず解説を出す。** ここを飛ばすとコンセプトが消える
- 解説はカレンダーから読み返せるので、飛ばしても失われない

### 3-3. 自由入力の判定（LLMなし）

**作問時に書くのは3つだけ**

```json
{
  "canonical": "本能寺の変",
  "reading":   "ほんのうじのへん",
  "en":        "Honnoji Incident",
  "suffixStrip": true
}
```

**ビルド時の自動生成**

1. `reading` からカタカナ表記を機械変換（かな⇔カナは1対1なので手で書く必要なし）
2. `suffixStrip` が true なら、定型接尾辞を末尾から剥がしたバリアントを生成
   接尾辞リスト：`の変` `の乱` `の役` `の戦い` `の陣` `時代` `天皇` `朝` `家` `藩` `城` `川` `山` `県` `法` `条約` `事件` `主義` `学` `説` `の定理` `の法則`
3. 各バリアントについて 漢字 / かな / カナ / 英語 の4系統を展開

結果、「本能寺の変」の受理集合は8通りになります。

```
本能寺の変 / 本能寺 / ほんのうじのへん / ほんのうじ
ホンノウジノヘン / ホンノウジ / Honnoji Incident / Honnoji
```

**照合時の正規化**（v3で実装済みのものを流用）

全角英数→半角、カタカナ→ひらがな、半角カナ→全角、大文字小文字、長音記号・中黒・句読点・空白・括弧の除去。

**注意点：接尾辞剥がしは過剰許容を生みます。** 「本能寺の変が起きた寺は?」という問題で「本能寺の変」が正解になってしまう。だから `suffixStrip` は**問題ごとのフラグ**にし、枠が示されている問題（「◯◯の変」）や、接尾辞の有無が意味を変える問題では明示的に false にします。デフォルトは true でよいですが、CIの検証スクリプトで「同一教科内に、剥がした結果が衝突する解答がないか」をチェックします。

誤字脱字は不正解扱い、という方針どおりです。

### 3-4. レンジ回答の許容幅（自動算出）

**発想**：時代が古いほど、人類が持つ年代の記録解像度は粗い。だから許容幅は「現在からの隔たり」に比例させます。

```
age = 現在年 − 正解年
W   = clamp( round(age / 10) + 10, 10, 500 )
```

| 出来事 | 正解年 | 許容幅 |
|---|---|---|
| 東日本大震災 | 2011 | ±6年 |
| ベルリンの壁崩壊 | 1989 | ±7年 |
| 終戦 | 1945 | ±9年 |
| 明治維新 | 1868 | ±13年 |
| 関ヶ原の戦い | 1600 | ±26年 |
| 応仁の乱 | 1467 | ±33年 |
| 鎌倉幕府の成立 | 1192 | ±46年 |
| 平安京遷都 | 794 | ±66年 |
| 秦の統一 | −221 | ±117年 |
| クフ王のピラミッド | −2560 | ±234年 |

手で決めた場合とほぼ同じ値になります。**オーバーライド用に `precision` 係数（既定1.0）だけ持たせておけば十分です。** 語呂で覚えられる年（1600、1492、1868）は 0.5 にして厳しくし、諸説ある年代は 2.0 に緩める、といった微調整に使えます。

**採点**

```
回答レンジ [a, b]（a ≦ b）、正解年 Y
Y ∉ [a, b]        → 0点
幅 = b − a
score = round(1000 × (1 − 幅 / W))、下限50点
a = b = Y         → 1000点（満点）
```

範囲を広く取れば当たるが点は伸びない。狭く取るには知識が要る。**「どのくらい自信があるか」を賭ける形式**なので、知識の解像度がそのままスコアになります。

報酬連動：score ≥ 800 で魔石+1、= 1000 で追加のGUM。

### 3-5. その他の回答方式

| 方式 | 用途 | 採点 |
|---|---|---|
| 4択 | 既存 | 正誤 |
| **レンジ** | 年代 | 上記 |
| 並べ替え | 出来事の順序、地層、進化 | 隣接ペアの正解率で部分点 |
| 数値入力 | 計算、統計値 | 完全一致 or 誤差許容 |
| 地図ピン | 地理、都市の位置 | 実距離で減点 |
| 自由入力 | 用語、チャレンジ | 上記 |

### 4-2. チャレンジ再設計

現状はゲージを削るとLv0が汎用的すぎて、その英雄でなくても答えられます。

1. **1問1答をやめ3問構成に。** 必要正答数をレアリティで変える（Common 1/3、Rare 2/3、Legendary 3/3）
2. **Lv0でも固有名詞を要求。** 「向きが一定の電流」ではなく「エジソンが電流戦争で推した送電方式」。ゲージが変えるのは**問いの難しさ**であって、**その人物との距離**は変えない
3. **出題を人物の素性へ寄せる。** 教科書の一般論ではなく、その人の人生に触れないと答えられない位置まで踏み込む
4. **Legendaryは本当に難しくてよい。** ただし挑戦するたびにその人物にまつわる知識カードが1枚もらえる設計にして、負けるほど次が有利になるようにする
5. ゲージ上限の再調整：Legendary 100 → 140

### 8-1. 投資・貯蓄シミュレータ

GUM を「解いて増やす」だけでなく、**公民や経済の実践として運用して増やせる**ようにします。
中学公民の金融分野を、読んで終わりにせず手を動かして確かめる場にする狙いです。貯めた GUM を
預ける、配分を決める、時間を進めて結果を見る、という一連の操作そのものが教材になります。

うまくはまれば、GUM の性格が「行動量の副産物」から「**運用の対象**」へ広がります。ショップで
クリスタルを買う以外の使い道ができるので、経済系全体の厚みも増します。

**着手前に決めなければならないことが5つあります。** どれもコンセプトの根に触るので、
思いつきで実装しないでください。

| 論点 | 何が問題か |
|---|---|
| 原則2「ランダム報酬を入れない」との衝突 | 相場の変動は本質的にランダム。乱数で増減させると、そのまま射幸心の装置になり、いちばん避けたかった構造が裏口から入ってくる。**乱数を引かせない作りが要る。** 実在の指数の過去データをなぞる、決定論的なシナリオを何本か用意して選ばせる、といった案が考えられる |
| 原則6「通貨の役割を混ぜない」との整合 | GUM の入り口が増えても、**魔石は買えないままにする。** ここが崩れると、苦手分野に手を出す動機がゲーム内から消える |
| 元本を失う設計にするか | 原則3「不正解が罰にならない」と同じ理屈で、損失が罰として働くと、知的好奇心ではなく損失回避が動機になる。減る体験は学習上は重要なので、**減っても次の出題や解放が不利にならない**ことを担保する形を探す |
| 学年帯の対応 | 金融分野は中3。小学生の範囲を解いている段階で投資画面を出すかどうか。知識マップの到達度で解放する案がある |
| 実在の金融商品を出すか | 企業名や商品名を出すと商標と誤解のリスクを負う。クリスタルの商標の但し書きと同じ問題。**一般名詞と架空の銘柄で組む**のが無難 |

材料としては、既存の仕組みをそのまま使えます。カレンダーは日単位の記録装置としてすでに動いて
いるので、時間を進める操作の受け皿になります。知識カードは解放条件に使えます。
