## 2. 共通の基準で足りないもの

| 分類 | 足すもの |
|---|---|
| 画面の器 | `theme-color`（`--ink` #17243F） |
| 部品 | ボタンを押したときの手ごたえ（`:active` で少し暗く。**`transform` は使わない**——カードや英雄の絵に `transform` の演出が多く、重ねると崩れるため） |
| | ポップアップ（ヒント S-27・設定 S-28・SS S-34）に `role="dialog"` と `aria-modal`。**Esc で「とじる」を押したのと同じ動きにする**（時計もそこで動き出す。原則5の道具を使った人を罰さないため、止める・動かすは「とじる」と同じ道を通す） |
| | トーストに `role="status"`（`aria-live`） |
| 外向き | `manifest.json`（ホーム画面に追加）、アイコン（いまのファビコンの図柄を PNG に：48・180・192・512）、OGP と Twitter カード（1200×630） |
| 共通基盤 | `initPlatform` に版（`1.0.0`）を渡す |

### 入れないもの（基準から外れるが、意図した決定）

- **Google Fonts。** 本文と見出しは端末の明朝・ゴシック（`--mincho` / `--gothic`）。問題文を読ませるゲームなので、読み込みを待たせない
- **初めての人への案内。** 決定1（無説明の初回起動）。「教わらずにできた」から始めるのがこのゲームのテーマそのものです
- **音を最初から鳴らすこと。** 既定は OFF（CLAUDE.md「音」）
