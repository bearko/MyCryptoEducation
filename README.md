# 世界の教室

歴代の英雄とともに、世界の義務教育カリキュラムを旅するクイズゲーム。

「解ける爽快感 → 忘却の自覚 → 習っていない単元への遭遇 → 英雄による解説 → 越境できるようになる」という5段階を、1本の遊びとして通せることを目指しています。

---

## 動かす

```bash
npm start          # http://localhost:3000 で開く
```

`index.html` を file:// で直接開いても動きません。JSONを fetch しているためです。
サーバを立てずに配布したいときは、単一ファイルにビルドしてください。

```bash
npm run build      # dist/index.html （データも画像も1枚に畳んだ版）
```

## 検証する

```bash
npm run validate   # 問題DBの整合性チェック
node scripts/smoke.mjs   # 全画面を実際にクリックして回る通しテスト（要 jsdom）
```

`npm run validate` は在庫の一覧も出します。**1教科あたり10問を下回ると警告が出ます。**
1セッションが10問なので、これを下回る教科は出題が短く終わります。
あわせて 教科×学年 の表を出し、空きマスと10問未満のマスを警告します。
表の「−」は、日本の義務教育にその組み合わせが無いことを示します（`data/curriculum.json`）。

## デプロイ

`main` への push で Vercel が本番へ、それ以外のブランチへの push はプレビューURLへ
自動デプロイします。ビルド不要の静的サイトで、リポジトリ直下をそのまま配信します。

**`vercel.json` の `outputDirectory` を消さないでください。** フレームワークを使わない
プロジェクトで `public/` があると、Vercel はそこを公開ディレクトリに選びます。
このリポジトリの `public/` は画像だけで `index.html` が無いため、既定のままだと
サイト全体が 404 になります。`"outputDirectory": "."` がそれを止めています。

Vercel は `package.json` に `build` スクリプトがあるので `npm install` と
`npm run build` を走らせますが、配信されるのはリポジトリ直下なので結果は使いません。
デプロイを速くしたい場合は、Vercel の Project Settings → Build & Development Settings で
Build Command を空にしてください。

## ディレクトリ

```
data/          問題と設定（ここを増やすのが本体）
  questions/   教科別JSON
  heroes.json  英雄・チャレンジ問題
  extensions.json / gemstones.json / figures.json
public/        画像
src/           アプリ本体
  normalize.js 表記ゆれの吸収
  engine.js    出題ロジック・難易度ゲージ（純粋関数）
  data.js      JSONの読み込みと索引づくり
  state.js     ゲーム状態
  views.js     画面描画
scripts/       検証・ビルド・アセット取得
```

`engine.js` はDOMに触れません。出題や難易度の計算はここだけを読めば追えます。

## 問題データの書き方

`data/questions/<教科>.json` に配列で追加します。

```json
{
  "id": "shakai-010",
  "chapter": 1,
  "grade": "j2",
  "gradeLabel": "中学2年",
  "subject": "社会",
  "unit": "中世の日本",
  "country": null,
  "newCurriculum": false,
  "figure": null,
  "format": "choice",
  "prompt": "応仁の乱が起こったのは何時代か?",
  "choices": ["鎌倉時代", "室町時代", "安土桃山時代", "江戸時代"],
  "answer": 1,
  "hints": ["1467年のことだ。", "将軍家の跡継ぎ争いが発端でな。", "その将軍家の姓は足利。ならば、いつの世か。"],
  "lesson": "1467年、8代将軍足利義政の……",
  "tip": "わたくしが暮らした都は、この乱でほとんど焼けてしまいました。……",
  "card": "応仁の乱",
  "applied": {
    "prompt": "応仁の乱が起きたときの将軍は?",
    "choices": ["足利尊氏", "足利義満", "足利義政", "足利義昭"],
    "answer": 2,
    "hint": "銀閣を建てた将軍だ。",
    "note": "足利義政。政治から離れて東山に銀閣を建てた。……"
  }
}
```

| 項目 | 意味 |
|---|---|
| `chapter` | 0=日本の小学校 / 1=日本の中学校 / 2=現行課程の新単元 / 3=世界の12歳 |
| `grade` | `e1`〜`e6`（小学校）、`j1`〜`j3`（中学校）、`w`（世界） |
| `country` | 海外の問題のみ。「インド / Class 7（12歳）」のように表示される |
| `format` | `choice`（既定）か `range`。`range` は `year` を持ち、`choices` と `answer` を持たない |
| `newCurriculum` | true にすると学年バッジが赤くなる |
| `figure` | `figures.json` のキー。SVG図版を表示する |
| `hints` | **必ず3つ。第3ヒントも答えそのものは書かない。** validate が検出します |
| `tip` | 「もう少しだけ知りたい」で、別の英雄が横から言う一言 |
| `card` | 獲得する知識カード名。英雄の解放条件に使われる |
| `image` | `data/images.json` のキー。コモンズの写真を1枚出す |
| `imageAt` | `prompt`（問題文の下）/ `hint`（第3ヒント）/ `lesson`（解説の中、既定） |

### ヒントの書き方

第3ヒントは「答えの直前で止まる」のが原則です。処理の手順は渡しても、最後の一手は残します。

- ✗ 「10 + 3 だ。」
- ✓ 「10を作ったあと、5から使った分を引く。それを10に足す。」

`npm run validate` は、第3ヒントに正解の選択肢がそのまま含まれていると警告を出します。

## 素材とライセンス

| 素材 | 出典 | 条件 |
|---|---|---|
| 英雄・エクステンション・背景・魔石 | MyCryptoHeroes | MCH社から許諾を取得済み |
| クリスタル100種 | CC0（パブリックドメイン） | 自由に利用可。**ただし商標にはCC0が及ばないため、提供元の名称はゲーム内で使わない** |
| 写真素材 | Wikimedia Commons | PD と CC BY を優先。CC BY-SA は改変物に同ライセンスが波及するため避ける |

アセット取得スクリプトは手動で実行します。CIでは走らせません。

```bash
node scripts/fetch-mch-assets.mjs   # 英雄・背景・アイコン・魔石
node scripts/fetch-crystals.mjs     # クリスタル100種
node scripts/fetch-commons.mjs      # Wikimedia Commons の写真（data/images.json を埋める）
```

### 写真を足す

1. `data/images.json` の `images` に、キーと `search`（検索語）と `alt`（説明）を書く
2. `node scripts/fetch-commons.mjs` を走らせる。`allow` にあるライセンスの候補だけを採り、
   題名・作者・ライセンス・出典を台帳に書き戻す
3. 採れた画像を目で確かめる。**ライセンスは機械が見ますが、写っているものが問題に合うかは人が見ます**
   - 「使えるライセンスの候補がありません」と出たら、見えた候補が題名つきで並ぶ。
     コモンズで PD か CC BY の1枚を選び、台帳のその項目に `"commons": "File:〜.jpg"` を足すと、
     次の実行でそれを直接採る。`"category": "〜"` を足して検索範囲を絞ることもできる
4. 問題データに `"image": "<キー>"` と `"imageAt": "prompt" | "hint" | "lesson"` を足す
5. `npm run validate` を通す

使えるのは PD・CC0・CC BY だけです。CC BY-SA は改変物に同じライセンスが波及するので使いません。
クレジット（作者・ライセンス・出典）は画像のすぐ下に必ず出ます。表示を消すとライセンス条件を満たしません。
